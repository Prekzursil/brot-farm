# ADR 0001 — APRS: Attractor Parameter Record Set

**Status:** accepted (2026-10-21) · **Default per program §9**

APRS is the interchange format for a fractal-darkroom *experiment as a shareable
artefact*: a versioned, human-readable JSON document with the extension
`.aprs.json`. Field set (all required, no additional properties):
`schema.version` (integer, currently `1`), `name`, `grammar`
(`{family, real, imag, power}` — the exact operator grammar of
`brot_build.py`: family `mutation|fold|power`, real
`cos|sin|tan|sinh|exp|abs`, imag `plain|cos|abs|neg|absxy`, power `2..5`),
`window` (`[x0, x1, y0, y1]`, ascending), `caps` (3 ascending iteration caps,
each `0 < cap ≤ 100000` — matching the build-suite channel sanity bar),
`gamma` (tone gamma, `0 < γ ≤ 10`), `notes`, `author`, `created` (RFC 3339 with
timezone), `renderer` (const `"fractal-darkroom"`), `provenance`
(`authored-on-site` — produced by the on-site playground/CLI — or
`imported-bundle` — a record that entered through a bundle), and `preview`
(`sha1[:8]` of a 128 px preview PNG, or `null` when the producer rendered
none). The preview hash doubles as the content-identity key: the community
collection stores each record as `collection/<hash>.aprs.json` and dedupes on
it. Two structural documents pin the contract: `docs/aprs.schema.json` (JSON
Schema draft-07, `additionalProperties: false`) and the stdlib-only authority
`scripts/validate_aprs.py`, which enforces the schema *plus* the cross-field
rules draft-07 cannot express (window/caps ordering, RFC 3339 parsing, hex
preview). Both producers — the playground (JS field-for-field mirror of the
same rules) and `brot_build.py aprs` (self-validates before writing) — must
emit files the validator accepts; intake (`.github/workflows/aprs-intake.yml`)
re-validates and never merges: a human curates every PR.

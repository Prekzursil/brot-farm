The APRS collection

Every entry is an APRS — an Attractor Parameter Record Set (.aprs.json, ADR 0001): a complete, human-readable recipe for one attractor — operator grammar, window, iteration caps, tone gamma, and a preview hash that doubles as its fingerprint. Submissions arrive through the APRS issue form, get validated by scripts/validate_aprs.py, deduped by preview hash, and are merged only by a human curator. Want in? Author a map in the playground, hit export APRS, and attach the file.

    How to read a record

    grammar picks the iteration rule from the same operator grammar as brot_build.py; window is the plot rectangle; caps are the three channel iteration caps; gamma is the tone-mapping exponent; preview is sha1[:8] of the 128 px preview PNG — the record’s content fingerprint and file name. Provenance badges: authored-on-site (made in this playground or with the build suite CLI) vs imported-bundle (arrived inside a bundle).
